# Paperwing experiments

Small, working prototypes exploring how agents can create and revise artifacts.
These projects are shared as references; expect rough edges and no support
commitment.

## Experiments

### [Composer](composer/)

Conversational 3D generative art built with Flue, Cloudflare Code Mode, React,
and Three.js. The agent writes a bounded JavaScript geometry program, an
isolated Dynamic Worker runs it, and a trusted renderer turns the result into
an editable sculpture.
